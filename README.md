# Muluken Bekalu, Full-Stack Developer Portfolio

Portfolio site built with plain HTML and CSS (no build step).

## Files
- `index.html`: the whole site (styles are inside the file)
- `assets/profile.jpg`: profile photo

## Run locally
Open `index.html` in your browser.

## Push to GitHub
```bash
cd portfolio-repo
git init
git add .
git commit -m "Add portfolio"
git branch -M main
git remote add origin https://github.com/mulukenbekalu529-cyber/YOUR-REPO-NAME.git
git push -u origin main
```

## Host it free on Netlify
1. Netlify > Add new project > Import from GitHub, choose this repo.
2. Leave the build command empty and set the publish directory to `.`
3. Deploy, then set Project visibility to Public so anyone can open it.
